# Security policy

Avoid putting secrets or private device material in any public report. In
particular, never attach Bluetooth LinkKeys, pairing credential files, or raw
private credential dumps.

If this repository's **Security** tab offers **Report a vulnerability**, use
that private GitHub form for security-sensitive issues. Its availability
depends on repository settings; this document does not claim it is enabled. If
the form is unavailable, open a minimal public issue asking the maintainers to
arrange a private reporting channel. Include no exploit details, credentials,
captures, hardware identifiers, or other sensitive material in that issue.

Ordinary bugs that contain no sensitive information may use the public issue
tracker. Describe the affected version, expected behavior, and a minimal safe
reproduction.
